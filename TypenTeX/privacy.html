隐私说明

更新日期：2026-11-05 · 适用于 TypenTeX Android 版

TypenTeX 是一款本地运行的 LaTeX 编辑器，不收集、也不上传你的文档内容。下面逐项说明应用会接触到哪些数据，以及联网发生在什么时候。

一、不收集的信息

  • 不采集设备标识符、IMEI、MAC 地址、位置、通讯录、剪贴板等任何系统信息；
  • 不含统计埋点、崩溃上报、广告或第三方分析 SDK；
  • 不会把你的 .tex、.bib、图片、生成的 PDF 或编译日志发送到任何服务器。

二、仅在本机读写的数据

数据位置用途
项目文件你通过系统文件选择器授权的目录编辑、编译、重命名、移动
page_info.txt项目根目录（可自行删除）记住 PDF 阅读位置（页码、缩放、页内位置）
编译日志应用内显示，不外传排查编译错误
宏包缓存应用私有目录避免重复下载，支持离线编译

应用只访问你明确授权的目录，不会扫描其他存储位置。

三、联网行为（仅两处）

  1. 检查更新：在菜单里点击检查更新时，向 api.github.com 请求本项目的最新发布信息，用于比较版本号。该请求不携带任何用户数据，但按 HTTP 协议，GitHub 会收到你的 IP 地址与常规请求头；是否发起检查完全由你触发，应用不会在后台自动检查。
  2. 首次编译下载宏包：编译所需但本地尚未缓存的 TeX 宏包，会从 Tectonic 的官方宏包源下载。该过程只传输宏包文件，不包含你的文档内容；缓存完成后，后续编译可完全离线进行。

除此之外应用不会主动联网。

四、权限说明

权限原因
存储 / 目录访问通过系统文件选择器（SAF）读写你指定的 LaTeX 项目目录
网络上述检查更新与宏包下载

五、数据留存与删除

  • 所有数据都在你的设备上，卸载应用后应用私有目录（含宏包缓存）随之删除；
  • 项目目录内的文件（含 page_info.txt）由你自行管理，卸载应用不会删除它们；
  • 由于不收集任何数据，不存在「向开发者申请删除个人数据」的情形。

六、第三方组件

应用内置的第三方组件（Tectonic、Flutter、pdfx 等）不包含任何数据采集功能，其许可信息见 许可与声明。

七、变更与联系方式

本说明如随功能变化而调整，会在本页更新并注明日期。对本说明有疑问，或发现与描述不符的行为，请提交 GitHub Issue。
